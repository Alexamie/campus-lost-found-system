# Context

## Application Overview
The Campus Lost and Found System is a web-based application built with a NestJS backend and an HTML/CSS/JavaScript frontend.

It allows students, staff, and visitors to:
- Report lost or found items
- Browse item listings
- Submit claims
- Access helpful campus resources

Currently, the system uses localStorage for frontend-only persistence, with plans for backend database integration.

## Problem Statement
Many campuses lack an efficient and centralized system for managing lost and found items, leading to low recovery rates and poor tracking.
