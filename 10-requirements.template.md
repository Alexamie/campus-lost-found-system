# Requirements

## Functional Requirements
1. User Authentication (Login/Register)
2. Dashboard Navigation
3. Report Lost/Found Item
4. View Lost Items
5. View Found Items
6. Claim Items
7. Sidebar Navigation
8. Helpful Resources Page
9. Contact/Help Page
10. Claims Management

## Non-Functional Requirements
- Usability: Simple and intuitive UI
- Performance: Fast page loading
- Security: Basic authentication
- Scalability: Future backend integration
